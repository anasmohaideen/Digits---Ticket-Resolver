## Round 3: reply editor, Ask AI panel, avatar badges

- Reply bar: "Reply using AI" and "Ask AI" are now AI Design System ActionButtons; Reply using AI opens the shared ReplyEditorAiMenu (Generate reply, Suggest resolution steps, Acknowledge, Request more information, Follow up, Request confirmation to close). Reply / Forward / Note stay Dew buttons.
- Editor strip: Freddy mark, inactive "Refine" label and custom dropdown replaced by Refine (Expand, Rephrase, tone), Reply using AI and Edit with Copilot ActionButtons (rte appearance, mini). Refine is a canned text transform.
- Ask AI panel: now a separate floating card (border, large radius, shadow) on a container-fill canvas with spacing-100 gap, headed by the Dew AI wordmark.
- Avatars: channel (Slack/Teams) badges are circular with a 1px ring.

## Round 4: working AI actions, card actions, scrollbars

- Reply editor AI menus (Reply using AI, Refine) now anchor to the clicked button (the old ref could point at a hidden duplicate, so the menu opened off-screen). Menu clicks no longer steal the editor selection.
- Refine works on the selection if there is one, else the whole draft. Edit with Copilot is disabled until text is selected in the editor, then opens Ask AI with that text.
- Summary / Root cause card: Regenerate replays the thinking banner then refreshes (feedback resets); Copy writes to the clipboard and shows "Copied to clipboard"; Edit swaps the body for a textarea with Save/Cancel and shows an "Edited by you" tag.
- Scrollbars are hidden until an element scrolls, then fade after ~0.9s.

## Round 5: AI Design System panels

- Ask AI now uses the AI Design System slider: SliderContainer chrome (Dew AI wordmark, new conversation, minimize, close, enter glow), welcome block, AiPromptSuggestion chips, AiInputBox, AIResponse / UserMessage thread.
- Edit with Copilot (reply editor) opens the AI Design System CopilotPanel in the same slot: quote chip of the selection, rewrite thread, regenerate/copy, "Add to composer" replaces the selection.
- Refine menu icons use the Dew icon library (TextAreaExpand, Refresh, MyWork, Conversation, CSATHappy) instead of the heavy inline glyphs.

- Minimized Freddy panel: collapses to the 52px header card floating top-right, the conversation reclaims the full width, and Expand restores the panel (the dock was forcing full height).

- Regenerate: no inner banner; the card border animates (AI gradient drift) while the tabs are disabled, then returns. Copy: Dew success toast "Copied to clipboard", auto-closes after 5s.

- Regenerate body shows the Dew-AI AiShimmer skeleton lines instead of the dimmed text.

- After the shimmer, regenerate writes a new summary / root cause with the Dew-AI generating-text reveal and the byline updates to "just now".

- Regenerated text reveals once; switching Summary / Root cause tabs no longer replays it.

## Round 6: rich text in the reply editor and thread

- Editor toolbar (full set for email and portal, basic for Slack/Teams) is now functional: paragraph style, bold/italic/underline/strike, text colour, highlight, align, indent, lists, link (inline URL row), code (inline or block), image (file or paste, PNG/JPG/GIF/WebP up to 2 MB), table, clear formatting. Pasted HTML keeps structure but loses colours and fonts.
- Sent drafts carry sanitised HTML (`MessageNode.html`) beside the plain text. The thread renders it in a neutral content well (`RichHtmlView`, `richHtml.ts`): no inline styles, scripts, iframes, event handlers or javascript: links; code scrolls with a Copy button; tall code is capped; images fit the card and fall back to alt text when broken; tables scroll sideways; long strings wrap.
- New ticket INC-4160 shows one case per message: formatted steps with links and strike, inline and block code with a long line, inline and broken images, a wide table, Outlook-style pasted HTML with hostile styles and scripts, a quoted chain with unbroken strings, emoji / RTL / CJK / nested lists, and a long log excerpt.

## Round 7: unified across tickets

- Regenerate now rewrites each ticket's own summary / root cause / resolution from its data (it was Wi-Fi text on every ticket).
- INC-4160 gets its own on-demand summary and root cause, so "Summarize ticket" and "Find the likely cause" work there like INC-4150.
