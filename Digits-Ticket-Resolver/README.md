# Digits – Ticket Resolver prototype

- `Digits-Ticket-Resolver-standalone.html` — open in a browser, no install (default route: ticket INC-4127).
- `source/` — Vite + React + TypeScript project. Run `pnpm install` (or `npm install`), then `pnpm dev`; `pnpm test` runs the 58 tests; `pnpm build` makes a production build.
- `Docs/` — design guidelines (start with `Digits-Ticket-Details-Design-Guidelines.md`), change log and audits.
